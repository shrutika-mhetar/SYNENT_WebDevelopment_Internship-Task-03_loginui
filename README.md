# ✨ Nova Login UI

A modern and responsive Login Page UI designed with a clean glassmorphism interface and smooth user interactions.

## 📌 Project Overview
This project focuses on creating a professional authentication interface with an elegant user experience and responsive layout.

## 🚀 Features
✔ Responsive Design  
✔ Email & Password Input  
✔ Show / Hide Password  
✔ Remember Me Option  
✔ Forgot Password UI  
✔ Social Login Buttons  
✔ Modern Glassmorphism Design  

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript

## 📱 Responsive
Optimized for Desktop and Mobile devices.

## 🎯 Learning Outcome
Improved UI design skills, responsive layouts, and JavaScript interaction handling.
